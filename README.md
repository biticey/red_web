# 赤脉 · The Red Thread

红色文化主题单页网站 · 红色网页设计大赛参赛作品

---

## 这是个什么

一个讲红色文化的单页网站，用 HTML、CSS 和原生 JS 写的，没用什么框架。

整站就一条线索：一条红线。底色是深红，线是旧金色，字是米白色。主题就是顺着这条线，从 1921 年一直走到今天。

站里没用一张图片。首屏的光、地图、山形、粒子，全是代码画出来的。好处是：

- 不依赖任何外部文件，打开就是完整效果
- 图片加载不出来这种事不会发生
- 也没有素材版权问题

## 页面里有什么

顶部有六个导航：序、峥嵘、关键、地标、精神、致敬。

| 区块 | 内容 | 能干嘛 |
|---|---|---|
| 首屏 | 大字「赤脉」、几个关键年份、滚动提示 | 火星粒子在飘，光会跟着滚 |
| 走马灯 | 1921 到今天的几件大事 | 自动滚，鼠标放上去就停 |
| 序 | 一段话讲这条线是什么 | 滚到才出现，数字会跳 |
| 峥嵘岁月 | 五个年份卡片 | 能拖、能滚轮滑、能点箭头；点卡片会弹出那一年更细的经过 |
| 关键一步 | 六次改变走向的决定：三湾改编、古田会议、遵义会议、西安事变、《论持久战》、三大战役 | 鼠标划过去整行会亮 |
| 红色地标 | 一张坐标图 + 右边详情 | 点哪个点，右边就换哪个 |
| 精神谱系 | 五种精神 | 点左边标签，右边内容跟着换 |
| 诗里的话 | 两句长征诗 | — |
| 点亮一盏灯 | 给没留下名字的人点灯 | 点一下出一片光点，数字往上加 |
| 页脚 | 作品信息、目录 | — |

## 技术上

- 没有框架，没有 CDN，没有字体文件
- 手机、平板、电脑都能看，手机上有个全屏菜单
- 键盘也能用：Tab 能走到地图上的点，回车能切换
- 页面本身很轻：HTML 16KB，CSS 24KB，JS 16KB
- 系统开了「减少动画」的话，粒子、视差、走马灯都会自动关掉

## 本地打开

双击 `index.html` 就能看。
想用本地服务器（个别浏览器对 `file://` 有限制，推荐这个）：

```bash
python -m http.server 8000
# 或者
npx serve .
```

然后打开 `http://localhost:8000`。
